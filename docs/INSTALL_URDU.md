# ٹیلر ماسٹر پرو — انسٹال کرنے کا طریقہ

## ۱۔ APK ڈاؤن لوڈ کریں

1. فون میں **Chrome** کھولیں۔
2. یہ لنک کھولیں:
   **https://github.com/ajmalgazad/tailor-master-pro/releases/latest/download/TailorMasterPro.apk**
3. فائل ڈاؤن لوڈ ہونے دیں۔ اگر Chrome پوچھے کہ "یہ فائل نقصان دہ ہو سکتی ہے" تو **پھر بھی ڈاؤن لوڈ کریں** دبائیں۔
   (یہ ایپ Play Store سے نہیں آ رہی، اس لیے فون یہ وارننگ دیتا ہے۔)

## ۲۔ انسٹال کریں

1. ڈاؤن لوڈ مکمل ہونے پر **کھولیں (Open)** دبائیں۔
2. اگر فون کہے **"نامعلوم ایپس انسٹال کرنے کی اجازت نہیں"** تو:
   - **سیٹنگز (Settings)** دبائیں۔
   - **Allow from this source / اس ذریعے سے اجازت دیں** آن کریں۔
   - واپس آئیں۔
3. **انسٹال (Install)** دبائیں۔
4. اگر **Play Protect** پوچھے تو **More details ← Install anyway** دبائیں۔
5. انسٹال ہونے کے بعد **کھولیں** دبائیں۔

## ۳۔ پہلی بار استعمال

1. **بیک اپ اور سیٹنگز ← دکان اور عمومی سیٹنگز** میں دکان کا نام، فون اور پتہ لکھیں۔
2. **ریٹ ماسٹر** میں اپنے سلائی کے ریٹ درست کریں۔
3. **بیک اپ اور سیٹنگز ← بلوٹوتھ پرنٹر** سے پرنٹر جوڑیں اور **ٹیسٹ پرنٹ** کریں۔
4. چاہیں تو **PIN لاک** لگا لیں۔

ایپ آزمانا چاہیں تو **سیٹنگز ← نمونہ ڈیٹا شامل کریں** دبائیں۔ اصل کام شروع کرنے سے پہلے **نمونہ ڈیٹا ختم کریں** ضرور دبائیں۔

## ۴۔ نیا ورژن (اپ ڈیٹ)

نیا ورژن اسی لنک سے ڈاؤن لوڈ کر کے انسٹال کریں۔ پرانی ایپ **ان انسٹال نہ کریں**۔
نیا ورژن پرانے پر انسٹال ہوگا اور آپ کا سارا ڈیٹا محفوظ رہے گا۔

## ⚠ ڈیٹا کی حفاظت

- تمام ڈیٹا صرف اسی فون میں محفوظ ہے۔ انٹرنیٹ کی ضرورت نہیں۔
- **ہر ہفتے** بیک اپ بنائیں: **بیک اپ اور سیٹنگز ← بیک اپ اور ریسٹور ← بیک اپ فائل بنائیں**۔
- بیک اپ فائل اپنے واٹس ایپ، ای میل یا Google Drive پر بھیج دیں۔
- **ایپ ان انسٹال کرنے، فون ری سیٹ کرنے یا نیا فون لینے سے پہلے** بیک اپ ضرور بنائیں، ورنہ ڈیٹا ختم ہو جائے گا۔
- نئے فون پر ایپ انسٹال کر کے **بیک اپ سے واپس لائیں (ریسٹور)** کریں۔

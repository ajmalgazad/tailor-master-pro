# ٹیلر ماسٹر پرو — استعمال کی ہدایات

## مین مینو

| نمبر | حصہ | کام |
|---|---|---|
| ۱ | ڈیش بورڈ | آج کی بکنگ، ڈیلیوری، وصولی، بقایا اور اخراجات ایک نظر میں |
| ۲ | کسٹمر ماسٹر | کسٹمر بنائیں، تلاش کریں، ترمیم کریں، غیر فعال کریں |
| ۳ | فیملی ممبرز | ایک کسٹمر کے والد، بیٹا، بھائی وغیرہ |
| ۴ | ناپ ماسٹر | ہر فرد اور ہر کپڑے کا الگ ناپ |
| ۵ | کپڑوں کی اقسام | کپڑوں کی فہرست اور ان کے ناپ کے خانے |
| ۶ | ریٹ ماسٹر | معیاری ریٹ، خصوصی ریٹ، اضافی سروسز |
| ۷ | نئی بکنگ | آرڈر بنانا |

| ۱۰ | پیمنٹ اور کھاتہ | وصولی، ریفنڈ، کھاتہ، بقایا لسٹ |

| ۱۴ | بیک اپ اور سیٹنگز | بیک اپ، PIN، رسید ڈیزائن، دکان کی معلومات |

## نیا کسٹمر

1. **کسٹمر ماسٹر ← نیا کسٹمر**۔
2. نام لازمی ہے، باقی خانے اختیاری ہیں۔
3. اگر یہی موبائل نمبر یا نام + ولدیت پہلے سے موجود ہو تو ایپ خبردار کرے گی۔
4. پرانا بقایا ہو تو **ابتدائی بیلنس** میں لکھیں۔
5. کسٹمر بنتے ہی **"ذاتی استعمال"** نام کا پہلا فیملی ممبر خود بن جاتا ہے۔

## فیملی ممبر

کسٹمر کھولیں ← **فیملی ممبرز** ← **+ نیا فیملی ممبر**۔ ہر ممبر کا ناپ اور آرڈر الگ رہتا ہے۔

## ناپ لینا

1. کسٹمر کھولیں ← فیملی ممبر کے نیچے **نیا ناپ**، یا **ناپ ماسٹر ← نیا ناپ**۔
2. کپڑے کی قسم چنیں؛ اس کپڑے کے خانے خود آ جائیں گے۔
3. اکائی (انچ یا سینٹی میٹر) چنیں۔ اعشاریہ لکھ سکتے ہیں، مثلاً 14.5۔
4. صرف اس پروفائل کے لیے اضافی خانہ بھی شامل کر سکتے ہیں۔
5. **ترجیحی (ڈیفالٹ)** آن ہو تو بکنگ میں یہی ناپ خود چُنا جائے گا۔

**ناپ تبدیل کرنا:** ناپ کھولیں ← **ناپ تبدیل کریں (نیا ورژن)**۔ پرانا ناپ ہسٹری میں محفوظ رہتا ہے۔
پرانے آرڈرز اور پرانی رسیدوں میں وہی ناپ رہے گا جو بکنگ کے وقت تھا۔

**کاپی بنانا:** ایک ناپ کی کاپی اسی فرد یا خاندان کے کسی اور فرد کے لیے بنا سکتے ہیں۔

## نئی بکنگ

1. **نئی بکنگ** ← کسٹمر منتخب کریں ← آرڈر کس فرد کے لیے ہے، وہ چنیں۔
2. **+ کپڑا شامل کریں** ← فرد، کپڑا اور تعداد۔ ریٹ اس ترتیب سے خود آتا ہے: ممبر کا خصوصی ریٹ ← کسٹمر کا خصوصی ریٹ ← معیاری ریٹ۔ ضرورت ہو تو ریٹ بدل سکتے ہیں۔
3. ایک آرڈر میں کئی کپڑے اور مختلف افراد کے مختلف ناپ لگ سکتے ہیں۔
4. اضافی چارجز (ارجنٹ، کڑھائی وغیرہ) اور رعایت (رقم یا فیصد) شامل کریں۔
5. ایڈوانس لکھیں۔ حساب فوراً اپ ڈیٹ ہوتا ہے:
   - کپڑوں کی رقم + اضافی چارجز − رعایت = کل رقم
   - کل رقم − وصولی = بقایا
6. **بکنگ کنفرم کریں**، یا بعد کے لیے **ڈرافٹ محفوظ کریں**۔
7. آرڈر کی اسکرین سے **بکنگ رسید** اور **ناپ کی پرچی** پرنٹ کریں۔

## آرڈر کا اسٹیٹس

نئی بکنگ ← ناپ مکمل ← کٹنگ جاری ← سلائی جاری ← فنشنگ ← تیار ہے ← ڈیلیور ہو گیا (یا منسوخ)

- ہر کپڑے کا اسٹیٹس الگ بدل سکتے ہیں۔ سب کپڑے ایک ہی مرحلے پر پہنچیں تو آرڈر کا اسٹیٹس بھی خود بدل جاتا ہے۔
- ہر تبدیلی وقت کے ساتھ **اسٹیٹس ہسٹری** میں محفوظ ہوتی ہے۔
- منسوخ یا ڈیلیور شدہ آرڈر رپورٹس اور ہسٹری میں موجود رہتے ہیں۔

## ڈیلیوری

1. **ڈیلیوری مینجمنٹ** یا آرڈر ← **ڈیلیوری**۔
2. جو کپڑے دیے جا رہے ہیں، وہ منتخب کریں۔ باقی کپڑے بعد میں دے سکتے ہیں (جزوی ڈیلیوری)۔
3. وصول ہونے والی رقم لکھیں۔
4. آرڈر تب تک "ڈیلیور ہو گیا" نہیں ہوگا جب تک سب کپڑے نہ دیے جائیں۔ آپ خود تصدیق کر کے آرڈر بند کر سکتے ہیں۔
5. محفوظ کرنے کے بعد ڈیلیوری رسید کھلے گی۔

## پیمنٹ اور کھاتہ

- **رقم وصول کریں**: کسٹمر ← آرڈر (اختیاری) ← رقم ← طریقہ (نقد، بینک، ایزی پیسہ/جاز کیش، دیگر)۔
- **ریفنڈ** اور **ایڈجسٹمنٹ** بھی یہیں سے درج کریں۔
- ہر اندراج کو ایک الگ نمبر ملتا ہے (T-00001)۔
- **غلط اندراج حذف نہیں ہوتا**۔ کھاتے میں اندراج پر دبائیں ← **منسوخ (ریورس) کریں**۔ ایک مخالف اندراج بن جاتا ہے اور دونوں ریکارڈ محفوظ رہتے ہیں۔
- رسید دوبارہ پرنٹ کرنے سے کوئی نئی وصولی **نہیں** بنتی۔

## اخراجات

**اخراجات ← نیا خرچ**: تاریخ، قسم، رقم، طریقہ۔ آج اور مہینے کا خلاصہ اوپر نظر آتا ہے۔
غلط خرچ **منسوخ** کریں (ریکارڈ محفوظ رہتا ہے)۔

## رپورٹس

روزانہ / ماہانہ بکنگ، کسٹمر ہسٹری، فیملی ناپ، کپڑوں کے لحاظ سے، زیر التوا، تاخیر والی ڈیلیوری، روزانہ وصولی، بقایا، اخراجات، آمدن و اخراجات کا خلاصہ، ریٹ ہسٹری۔

ہر رپورٹ میں تاریخ، کسٹمر، کپڑا اور اسٹیٹس کے فلٹر ہیں۔ **PDF** یا **CSV (ایکسل)** محفوظ کریں۔

## سیکیورٹی

- **PIN لاک** لگانے کے بعد ایپ کھولنے، ریکارڈ ضم کرنے، ریسٹور کرنے، نمونہ ڈیٹا ختم کرنے اور اندراج منسوخ کرنے پر PIN مانگا جاتا ہے۔
- PIN بھول جائیں تو صرف بیک اپ ہی ڈیٹا واپس لا سکتا ہے، اس لیے PIN کہیں لکھ کر رکھیں۔
- **آڈٹ لاگ** میں ہر اہم تبدیلی کا ریکارڈ ہے۔

## ڈپلیکیٹ کسٹمر

**کسٹمر ماسٹر ← ضم کریں**: غلطی سے دو بار بنے کسٹمر کو ایک کریں۔ تمام ممبرز، ناپ، آرڈرز اور ادائیگیاں اصل ریکارڈ میں منتقل ہو جاتی ہیں۔

## زبان (اردو / English)

- **فون ایپ:** سیٹنگز ← سب سے اوپر **Language / زبان** ← **English** یا **اردو** دبائیں۔
- **ویب ورژن:** بائیں / دائیں مینو کے نیچے، یا سیٹنگز میں **اردو / English** کے بٹن ہیں۔

انگریزی چننے سے پوری ایپ بائیں سے دائیں ہو جاتی ہے۔ رسیدیں، رپورٹس، PDF اور CSV بھی انگریزی میں بنتی ہیں۔

- آپ کا لکھا ہوا ڈیٹا (کسٹمر کے نام، نوٹس) ویسا ہی رہتا ہے۔
- کپڑوں، ناپ کے خانوں اور اسٹیٹس کے پہلے سے موجود نام انگریزی میں دکھتے ہیں۔
- زبان ہر فون یا براؤزر کی اپنی ہوتی ہے: ایک جگہ انگریزی اور دوسری جگہ اردو چل سکتی ہے، ڈیٹا ایک ہی رہتا ہے۔

# بلوٹوتھ تھرمل پرنٹر — سیٹ اپ اور ٹیسٹ

## کون سے پرنٹر چلیں گے

- **بلوٹوتھ ESC/POS** تھرمل پرنٹر، 58mm یا 80mm۔
- زیادہ تر سستے "Mini Thermal Printer / POS-58 / MTP-II / RPP02 / Xprinter / GOOJPRT" اسی قسم کے ہوتے ہیں۔
- ایپ **کلاسک بلوٹوتھ (SPP)** استعمال کرتی ہے۔ صرف BLE والے پرنٹر شاید نہ چلیں۔
- پرنٹر میں اردو فونٹ ہونا ضروری نہیں۔ ایپ پوری رسید کو **تصویر (bitmap)** بنا کر بھیجتی ہے، اس لیے اردو ہر اس پرنٹر پر صحیح چھپتی ہے جو تصویر پرنٹ کر سکے (ESC/POS `GS v 0`)۔

## پہلی بار جوڑنا

1. پرنٹر آن کریں اور کاغذ ڈالیں۔
2. فون کا **بلوٹوتھ** آن کریں۔
3. ایپ میں **رسید پرنٹنگ ← پرنٹر سیٹ اپ** کھولیں۔
4. **اجازت دیں** دبائیں اور Nearby devices / Bluetooth کی اجازت دیں۔
5. اگر پرنٹر **"جوڑے گئے"** فہرست میں ہے تو اس پر دبائیں۔ وہ منتخب ہو جائے گا۔
6. اگر نہیں ہے تو **نئے پرنٹر تلاش کریں** ← پرنٹر کے سامنے **جوڑیں** ← PIN مانگے تو **0000** یا **1234** لکھیں۔
7. **رابطہ جانچیں** دبائیں۔ "پرنٹر سے رابطہ ہو گیا" آنا چاہیے۔

## کاغذ کی چوڑائی

| کاغذ | عام چوڑائی (ڈاٹس) |
|---|---|
| 58mm | 384 |
| 80mm | 576 |

اگر رسید کا دایاں یا بایاں حصہ کٹ رہا ہو تو **پرنٹ ہونے والی چوڑائی** کم کریں، مثلاً 58mm کے لیے 360 یا 80mm کے لیے 512۔
کچھ 58mm پرنٹر صرف 360 یا 372 ڈاٹس چھاپتے ہیں۔

## ٹیسٹ پرنٹ — یہ چیک کریں

**رسید پرنٹنگ ← ٹیسٹ پرنٹ ← پرنٹ کریں**۔ چھپی ہوئی رسید میں یہ دیکھیں:

- [ ] تمام اردو حروف جڑے ہوئے اور صاف ہیں (ا ب پ ت ٹ ... ے)
- [ ] انگریزی ہندسے 0123456789 اور اردو ہندسے ۰۱۲۳۴۵۶۷۸۹ صاف ہیں
- [ ] علامات (، ۔ ؟ ! : % +) صحیح ہیں
- [ ] اردو اور انگریزی ملا جلا جملہ صحیح ترتیب میں ہے
- [ ] "بائیں / دائیں" والی لائن میں رقم بائیں طرف اور لیبل دائیں طرف ہے
- [ ] نیچے کی سیدھی لائن دونوں کناروں تک ہے اور کہیں سے کٹی ہوئی نہیں

اگر حروف بہت چھوٹے یا بڑے ہوں تو **رسید ڈیزائنر ← حروف کا سائز** بدلیں۔ تھرمل پرنٹر پر **نسخ** فونٹ زیادہ صاف چھپتا ہے۔

## پرنٹ کی حالت کا مطلب

| پیغام | مطلب |
|---|---|
| **رسید پرنٹ ہو گئی (پرنٹر نے تصدیق کی)** | پرنٹر نے جواب دیا کہ وہ ٹھیک ہے |
| **بھیج دی گئی، لیکن پرنٹر نے تصدیق نہیں کی** | ڈیٹا چلا گیا، لیکن بہت سے سستے پرنٹر جواب نہیں دیتے۔ کاغذ دیکھ لیں |
| **کاغذ ختم ہے** | نیا رول ڈالیں |
| **رابطہ نہیں ہو سکا** | پرنٹر آن کریں، قریب رکھیں، کسی اور فون سے منقطع کریں |

ہر پرنٹ کا ریکارڈ **رسید پرنٹنگ** میں ہوتا ہے۔ وہیں سے پرانی رسید دوبارہ پرنٹ کریں۔

## اگر پرنٹ نہ ہو

1. پرنٹر بند کر کے دوبارہ آن کریں۔
2. ایپ میں **منقطع کریں** ← **رابطہ جانچیں**۔
3. فون کی بلوٹوتھ سیٹنگ میں پرنٹر کو **Forget** کر کے دوبارہ جوڑیں۔
4. چیک کریں کہ پرنٹر کسی اور فون یا ایپ سے جڑا ہوا تو نہیں۔
5. پرنٹر کی بیٹری چارج کریں۔ کم بیٹری میں تصویر والی رسید ادھوری چھپ سکتی ہے۔

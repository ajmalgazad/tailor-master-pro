# کلاؤڈ سنک (فون + ویب) — سیٹ اپ

کلاؤڈ سنک سے دکان کا ایک اکاؤنٹ بنتا ہے۔ اس اکاؤنٹ سے فون ایپ اور ویب ورژن دونوں ایک ہی ڈیٹا دیکھتے ہیں۔

- انٹرنیٹ نہ ہو تو بھی دونوں چلتے رہتے ہیں، اور انٹرنیٹ آنے پر خود سنک ہو جاتے ہیں۔
- ڈیٹا دکان کے اپنے **Firebase (Google)** اکاؤنٹ میں رہتا ہے۔
- ایک دکان کے لیے Firebase کا مفت (Spark) پلان عام طور پر کافی ہے۔

## ۱۔ Firebase پروجیکٹ (ایک بار)

1. **console.firebase.google.com** کھولیں ← **Create a project** ← نام `tailor-master-pro` لکھیں ← Analytics بند ← **Create**۔
2. **Build ← Authentication ← Get started ← Email/Password ← Enable ← Save**۔
3. **Users ← Add user**: دکان کا ای میل اور پاس ورڈ بنائیں۔
4. **Build ← Firestore Database ← Create database** ← جگہ **asia-south1 (Mumbai)** ← **production mode**۔
5. **Firestore ← Rules** میں موجود سب کچھ ہٹا کر یہ لکھیں، پھر **Publish** دبائیں:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /shops/{shopId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == shopId;
    }
  }
}
```

یہ اصول یقینی بناتا ہے کہ ہر دکان صرف اپنا ڈیٹا دیکھ سکے۔

6. **Project settings ← Your apps**:
   - **Web (</>)** رجسٹر کریں اور `firebaseConfig` ڈویلپر کو دیں۔
   - **Android** رجسٹر کریں (package `pk.tailormaster.pro`) اور `google-services.json` فائل ڈویلپر کو دیں۔

## ۲۔ پہلی بار جوڑنا — ترتیب ضروری ہے

**پہلے فون، پھر ویب۔**

1. فون ایپ کا نیا ورژن انسٹال کریں ← **سیٹنگز ← کلاؤڈ سنک** ← دکان کا ای میل اور پاس ورڈ ← **لاگ اِن**۔
2. ایپ بتائے گی "کلاؤڈ ابھی خالی ہے" ← **جوڑیں**۔ فون کا سارا ڈیٹا کلاؤڈ پر چلا جائے گا۔
3. اب کمپیوٹر پر ویب ورژن کھولیں: **https://ajmalgazad.github.io/tailor-master-pro/app/** ← اسی ای میل اور پاس ورڈ سے لاگ اِن کریں۔

⚠ اگر ویب پر پہلے "نئی دکان" بنا دی، تو بعد میں فون جوڑنے پر فون کا موجودہ ڈیٹا ہٹ کر کلاؤڈ والا ڈیٹا آ جائے گا۔ اس لیے فون میں پہلے سے ڈیٹا ہو تو ہمیشہ **فون پہلے** جوڑیں۔

## ۳۔ دوسرا فون یا نیا فون

نئے فون پر ایپ انسٹال کریں ← **کلاؤڈ سنک ← لاگ اِن**۔ کلاؤڈ کا سارا ڈیٹا فون پر آ جائے گا۔

## ۴۔ نمبر

ہر فون اور براؤزر کو ایک ڈیوائس نمبر ملتا ہے تاکہ دو جگہ بنے ریکارڈ آپس میں نہ ٹکرائیں۔

- پہلے فون کے نمبر پہلے جیسے رہتے ہیں: `B-00012`۔
- دوسری ڈیوائس کے آرڈر نمبر میں ڈیوائس نمبر بھی آتا ہے: `B-2-0005`۔

دونوں طرح کے نمبر سے آرڈر تلاش ہو سکتا ہے۔

## ۵۔ مسائل

| پیغام | حل |
|---|---|
| کلاؤڈ نے اجازت نہیں دی (Rules) | Firestore Rules اوپر والے حصے کے مطابق Publish کریں |
| ای میل یا پاس ورڈ غلط ہے | Firebase ← Authentication ← Users میں چیک کریں |
| انٹرنیٹ نہیں ہے | کام جاری رکھیں۔ انٹرنیٹ آنے پر خود سنک ہوگا |

بیک اپ اب بھی بناتے رہیں۔ کلاؤڈ بیک اپ کی جگہ نہیں ہے۔
